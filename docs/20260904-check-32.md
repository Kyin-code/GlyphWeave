# check-32：静态预览、深圳湾精简版与通用素材契约初检

> 检查日期：2026-09-04
> 当前结论：**部分完成，不可宣称最终验收通过**。本轮先完成静态预览切换、深圳湾现有大桥产物复现与缺口审计；通用素材和 Rust 规则扩展尚未全部落地。

## 1. 背景

用户要求：

1. 暂停风场影响，只做静态画面，便于验收地形、道路、桥梁、建筑和遮挡；
2. 修复深圳湾精简场景中“桥没了”的问题；
3. 不只增加几个词条，而是建立通用素材类别、比例、位置和碰撞语义；
4. 最终形成精简版深圳湾（含大桥）测试场景，但项目主目标仍是通用地图生成器和 Agent 自然语言归化。

因此本轮不采用坐标补丁。所有新实体应通过 manifest/intent → Rust worldgen → descriptor/placement → HTML renderer 进入链路。

## 4. 通用规则现状

### 已有能力

- `EntityInstance` 有 `worldX/worldZ/worldY`、`widthM/depthM/heightM`；
- 已有 `rotationYDeg`、`GroundingSpec`、`Bounds2d`、`SpatialAnchor`；
- `computed_bounds()` 使用旋转后的 footprint；
- worldgen 有 OccupancyGrid；
- rules placement 有 descriptor、phase、priority、avoid、allow_rotate、fallback；
- Rust 生成顺序会先道路，再地块/建筑，再自然物；
- terrain carve 会为道路和建筑生成地形 pad；
- HTML 端有道路/植被 footprint 防御过滤。

### 仍缺少或不够通用

1. 新素材没有统一的 canonical kind / ItemKind 映射；
2. 新素材没有完整 `.object.toml` descriptor；
3. descriptor `GeometrySpec` 是固定 footprint，不能表达桥墩、围栏线段、步道线段、山体体积等 shape；
4. `PlacementContext` 的部分对象仍使用固定坡度/简化碰撞语义；
5. landmark 与 entity 的 renderer 分发不统一；
6. scene manifest 的桥梁、道路、滩涂、红树林之间还没有完整的 transition/clearance contract；
7. Intent 解析目前不能稳定识别购物中心、写字楼、便利店、护栏、步道、景观带、滩涂、夜市等细分类别并编译为正式 landmark/entity 语义。

## 5. 比例基线原则

本轮先采用可解释的通用范围，不把单个深圳湾坐标写进规则：

| 类别 | 初始建议范围 |
|---|---:|
| 普通山地 | 高度起伏 40–180m，坡度限制由地形 profile 负责 |
| 丘陵 | 高度起伏 8–60m，连续圆缓，避免锥形小山 |
| 岩石山体 | 体量 40–240m，硬碰撞，不能覆盖道路/建筑 |
| 大岩石 | 直径 2–12m，高度 1–8m，软景观碰撞 |
| 购物中心 | 80–260m × 60–220m，高度 12–45m |
| 写字楼 | 24–90m × 24–90m，高度 40–220m |
| 便利店 | 8–24m × 6–18m，高度 3–8m |
| 围栏 | 单段长度 8–80m，高 1.2–2.4m，线性 footprint |
| 护栏 | 单段长度 8–80m，高 0.8–1.4m，贴道路/步道边缘 |
| 步道 | 宽 2.5–6m，线性 footprint，硬表面 |
| 景观风光带 | 宽 20–120m，软/硬分层，不作为单一建筑盒子 |
| 红树林 | 单个树群 4–30m，必须靠岸/湿地 |
| 滩涂 | 20–300m 带状区域，软地表，禁止普通建筑 |
| 夜市 | 30–160m × 20–100m，高度 3–8m，靠近步道/道路 |
| 社区广场 | 25–120m × 25–120m，硬表面，靠近社区建筑/道路 |

这些数值是生成器的初始 contract，不声称代表所有真实城市；真实地点数据仍应覆盖 manifest 的显式尺寸。
