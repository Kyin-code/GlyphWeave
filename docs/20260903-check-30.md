## 2. 变更检查

### 2.1 PBR 地表：通过

- `adapters/html/render/terrain.js`
  - 新增 `makeTerrainPbrMaps()`；
  - normal 使用**同一 baked heightfield**的中心差分；
  - 输出改为 `MeshStandardMaterial` 所需的**切线空间**通道：R=X、G=Z/bitangent、B=up；
  - roughness 使用 wetness、disturbance、surface，不引入随机覆盖；
  - 贴图使用 `NoColorSpace`、clamp edge、linear filter；
  - 不做 vertex displacement。
- `adapters/html/app.js`
  - 高精度 steppe terrain 绑定 `normalMap`、`normalScale` 和 `roughnessMap`。

**不通过条件：** renderer 另行修改顶点高度、normal 不是由 baked 高度构建、道路/建筑 pad 仍被草或视觉噪声重新覆盖。
**本轮结果：** 未发现上述问题。

### 2.2 统一植被生态语义：通过

- 草：排除 `disturbance > .04` 与水/湿泥/岩地 surface；密度使用湿润度与坡度，高草考虑湿润凹地。
- 树：排除扰动、水面、陡坡与过干位置；尺寸、色相读取湿润度/坡度。
- 灌木与草丛实体：进入 renderer 前使用同一个 `vegetationFitsTerrain()`，不会通过 renderer 绕过生态约束。
- worldgen 仍先在生成端做自然物与道路、建筑的 footprint clear；renderer 只作一致的防御性过滤。

**不通过条件：** 树和草分别引入独立随机湿润度/坡度解释，或 renderer 能把生成端已排除的自然物重新显示在 road/building disturbance 区。
**本轮结果：** 语义入口统一为 `terrainAt()`。

### 2.3 世界风场：通过

新增 `adapters/html/render/wind.js` 的 `createWorldWind(THREE)`。草和树冠共享同一对象中的：

```text
uTime / uWindDir / uWindStrength / uWindSpeed / uWindScale / uGust
```

帧循环只更新一次 `worldWind.uTime`，避免草和树分别产生不一致的风向、风速或时间轴。

### 2.4 旋转建筑 footprint：通过

- `worldgen::footprint_surface_ceiling_m()`：采样旋转后的世界 X/Z 范围；
- `plan_terrain_carves()`：建筑 support pad 使用旋转后 half extent；
- `rules::audit`：审计 `Footprint` 使用同一个 helper；
- `rules::placement`：保留资产 local width/depth，不再在写入实体时二次交换尺寸。

新增测试：

```text
worldgen::tests::rotated_building_uses_world_footprint_for_grounding_and_pad
rules::audit::tests::audit_footprint_uses_entity_rotation
```
