# Manifest 严格 schema 验收报告（第 13 次）

- **日期**：2026-09-02
- **目标**：禁止 World Manifest 和关键结构未知字段被 serde 静默忽略。

## 已完成

以下结构启用 `deny_unknown_fields`：

- `WorldManifest`、`WorldSpec`、`SceneSpec`、`LandmarkSpec`；
- `SceneGraph`、`SceneTransition`；
- `GroundingSpec`、`Bounds2d`、`SpatialAnchor`；
- `SidecarContract`、`WorldPatch`。

`style` 仍保留自由 JSON 扩展区。外部参考、主题和实验参数尚未完成独立 schema；但所有影响拓扑、坐标、实体、场景关系和发布格式的字段已进入强类型结构。

## 验收清单

- [x] Manifest 顶层未知字段会解析失败。
- [x] 关键空间结构未知字段会解析失败。
- [x] 既有 examples 的 `sceneGraph` 可以正常读取。
- [x] 缺少 `sceneGraph` 的旧 Manifest 兼容为空图。

## 测试

`worldgen::tests::manifest_rejects_unknown_top_level_fields` 通过。

## 判定

**通过。** 关键用户意图不会再因顶层/空间模型未知字段而静默消失。
