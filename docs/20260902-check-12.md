# SceneGraph / Transition 强类型化验收报告（第 12 次）

- **日期**：2026-09-02
- **目标**：将早期需求中的 `sceneGraph` / `transitions` 从被 serde 忽略的未知字段，提升为 Core 正式类型。

## 已完成

修改 `bevy/crates/core/src/worldgen.rs`：

- 新增 `SceneGraph`；
- 新增 `SceneTransition`；
- `WorldManifest` 增加 `scene_graph`；
- `WorldIndex` 输出 `scene_graph`；
- transition 校验源场景、目标场景、源坐标、目标坐标、方向、ID 唯一性；
- `sceneGraph` 现在会被保留，不再静默丢失。

## 验收清单

- [x] 单场景 Manifest 可继续解析，缺少 sceneGraph 时使用空图。
- [x] 示例中的 `sceneGraph.transitions` 可被反序列化。
- [x] transition 的源/目标场景必须存在。
- [x] 源/目标坐标必须位于对应场景范围内。
- [x] transition ID 不能为空且不能重复。
- [x] sceneGraph 会写入最终 `world.json`。
- [x] 无效 transition 会让 Manifest 校验失败。
