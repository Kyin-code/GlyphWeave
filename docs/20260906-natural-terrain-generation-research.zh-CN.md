# 自然地形地貌生成研究与 Rust-first 重构设计

> 版本：v1.0（2026-09-06）
> 范围：GlyphWeave，最大 6 km × 10 km；本文件只做研究和设计，不实现代码。
> 目标：先得到可解释、可重复、可审计的自然地貌，再让 Rust Core 以工程实体方式叠加人类活动。

## 1. 对当前项目的判断

当前工程已经具备正确的工程化基础：最终 heightfield、分块 baked terrain、坡度/曲率/湿润度 sidecar、洪泛/水体查询、ReservationLayer、地形 carve、AccessGraph 和独立 audit。问题不在“没有更多噪声”，而在自然层仍容易被当作给建筑让路的背景：

- 噪声产生高频起伏，但没有明确的地质构造骨架；
- 水文常被推导为局部最低点，而不是从汇流、分水岭和沉积过程产生；
- 山脊、谷地、冲积扇、阶地、三角洲、海岸台地没有独立语义；
- 生成后缺少质量预算：河网密度、盆地数量、山脊连续性、坡向和沉积区没有审计；
- 人类工程若直接修改高度图，可能抹掉自然证据，或在建筑阶段反复互相覆盖。

因此不能仅把当前噪声替换成另一个噪声库。应将自然地形改为“宏观地质 + 水文 + 侵蚀沉积 + 生态场”的分层状态机。

## 2. 开源项目与可借鉴边界

### 2.1 Red Blob Games Mapgen4

Mapgen4 使用 dual mesh/Voronoi 网格，强调高效的地形、水文、降雨、蒸发、风和河流数据结构，并明确其目标是“好看而非真实地形”。它适合作为网格、河流拓扑和交互性能参考，不应直接当作 6×10 km 工程地形真值。其 Apache-2.0 许可允许商业使用。[1]

### 2.2 Azgaar Fantasy Map Generator

Azgaar 将高度图作为上游输入，后续河流、城市、道路、政治和生态数据依赖高度图；修改高度图后重新生成派生数据，避免旧河流和旧城市与新地形不一致。其教程还提供纬度、温度、风、降水和高度模板等控制项。[2] 这正好支持 GlyphWeave 的“自然先行、派生数据失效即重建”原则，但它是宏观地图，不是建筑级高度场。

### 2.3 FastNoiseLite / 多尺度噪声

FastNoiseLite 提供 OpenSimplex2、Perlin、Cellular 等连续噪声和频率/种子控制。[3] 它适合作为残差细节和材质扰动，不适合单独定义山脉、水系或城市可建设面。

### 2.4 液压侵蚀开源实现

公开实现通常以噪声高度场为初始面，模拟水滴的速度、水量、沉积物容量、侵蚀和沉积；质量守恒与可调步数是重要检查。它能产生谷纹和脊线，但滴落模型若直接用于大地图，成本高、边界敏感，不能替代宏观河网与地质语义。[4][5][6]

### 2.5 GIS/水文工具的启示

真实 DEM 工作流通常先做填洼、流向、汇流累积、河网和流域划分，再做洪泛、侵蚀、土地利用和工程分析。GlyphWeave 不必复制完整 GIS，但必须保留同样的依赖顺序和派生关系。

## 3. 推荐自然层级

```text
L0 地质/构造先验：地块、断裂、抬升区、沉降区、海岸基准
L1 宏观地貌：山系、丘陵、盆地、台地、平原、海岸和岛屿
L2 气候场：纬度、温度、降水、蒸散、主风向、雪线/植被带
L3 水文骨架：分水岭、汇水区、主河、支流、湖泊、泉、洪泛区
L4 侵蚀沉积：沟谷、冲积扇、阶地、三角洲、海岸侵蚀、风成沉积
L5 土壤与生态：土壤湿度、肥力、岩性暴露、林草、湿地、火险
L6 细节残差：岩块、微地形、自然裸地和局部粗糙度
L7 人类工程：道路、堤坝、削坡、填方、填海、挡墙、河道治理
```

核心原则：低层决定高层可行域；高层不能偷偷回写低层。人类工程产生新的 `EngineeredTerrain`，并保存对自然层的差异和原因。

## 4. 自然地形生成流程

### Stage N0：参数与宏观骨架

Agent 只提出：气候带、地貌原型、海平面、山系方向、河流/湖泊倾向、灾害偏好、自然度目标。Rust 根据 seed 生成构造场和大尺度控制线。用少量可解释的山脊曲线、盆地/台地 mask 和距离场形成宏观 relief，再用多尺度噪声添加残差。

### Stage N1：水文闭环

在初始 heightfield 上计算：

1. 填洼或标记内流盆地；
2. 流向/多流向；
3. 汇流累积；
4. 分水岭与河网；
5. 湖泊、湿地、洪泛区；
6. 河谷宽度与主河级别。

河流不是一条装饰折线，而是 `DrainageGraph`：有上游、下游、流量、河谷宽度、堤岸、穿越桥梁需求和季节性。

### Stage N2：侵蚀和沉积

优先使用“河网引导的侵蚀沉积”作为中尺度过程，液滴侵蚀只做局部残差。高汇流、高坡度、低植被区更容易下切；坡脚、河口、河流减速处形成沉积。质量预算必须近似守恒，边界出流单独记录。

### Stage N3：地貌语义化

从场和图中识别并持久化：

- 山脊：高程、连续性、宽度、分水岭关系；
- 山谷：谷轴、谷底宽度、坡度和水系；
- 盆地：封闭/开放、最低出口、湖泊或冲积平原；
- 冲积扇：山口、扇面、径流发散、可建设性差异；
- 河流阶地：相对高程、洪泛风险、适建台地；
- 三角洲：分汊、沉积、软土和高风险；
- 海岸：沙滩、基岩、潮滩、悬崖、海堤需求；
- 台地/断崖：平台、崖线、可通行缺口；
- 岛屿/半岛：潮汐连接和桥梁候选。

这些对象不是渲染标签，而是后续聚落、道路和工程的约束输入。

## 5. 让地形更自然的具体规则

1. **低频先行**：宏观地貌波长至少是地图短边的 1/5–1/2；高频噪声振幅不超过宏观起伏的受控比例。
2. **连续性**：山脊和谷地用曲线/距离场保持长程相关，不用独立 cell 随机高低。
3. **非对称侵蚀**：迎风/背风、岩性、植被和坡向影响侵蚀，不做均匀 radial noise。
4. **水文决定谷地**：主河先定义谷轴和汇水，再生成河岸台阶、冲积平原和支流，而非在最终高度图上寻找几条线。
5. **边界有上下文**：6×10 km 地图边缘要以虚拟外部汇水/山脉 continuation 处理，避免边缘突然截断山谷和河流。
6. **岩性分区**：软岩形成宽谷/缓坡，硬岩形成峡谷/陡崖；可先用抽象地质类别，不必做真实矿物。
7. **沉积反馈**：河口、山口、湖滨和海岸的低坡区生成沉积地貌；不要把所有低地都设成平面。
8. **自然不等于全随机**：应让少数大结构占据大部分解释力，细节仅补充纹理。

## 6. 自然场与人类工程的接口

所有人类活动只能通过显式工程操作改变地形：

```text
cut      挖方/削坡
fill     填方/台地
retain   挡墙/护坡
embank   堤坝/路堤
reclaim  填海/填湖/滩涂成陆
channel  河道整治
bridge   架桥
culvert  涵洞
terrace  梯田/台地
```

每个操作记录：几何 footprint、原始自然场版本、目标高程、材料体积、排水影响、边坡稳定性、相邻对象影响、施工原因和审计状态。工程完成后生成 `final_heightfield = natural + ordered_engineering_deltas`，而不是覆盖原始高度图。

工程优先级：保育/水体和灾害边界 > 主排水 > 桥梁/堤坝 > 主路 > 次路 > 地块平台 > 建筑地基 > 装饰性微地形。建筑不能要求 Rust 删除河流或把洪泛区抬高而不付出工程成本。

## 7. 与聚落生成的耦合

自然层完成后输出可建设性不是单一 bool，而是：

```text
BuildabilityScore
  slope_capacity
  flood_risk
  soil_capacity
  access_cost
  earthwork_cost
  ecological_sensitivity
  view/exposure
  existing_feature_conflict
```

城市、村庄和荒野依此选址：

- 平原/河流高台：高密聚落、农田、交通枢纽；
- 冲积扇：村镇/农业可行，但需排洪和避开主冲沟；
- 陡坡/峡谷：线性道路、台地、桥梁、低密设施；
- 三角洲/湿地：堤防内聚落、码头和保育分区，不能均匀填满；
- 海岸台地：旅游/港口/住宅分段，并保留公共岸线；
- 山脊和泉点：视线、供水或宗教节点，但必须通过灾害和供水审计。

## 8. Agent 与 Rust Core 职责

### Agent

- 将用户叙述映射为 `NaturalWorldIntent`；
- 选择地貌原型和参数范围；
- 解释方案、提出多个候选；
- 不生成最终几何，不直接改高度图，不绕过审计。

### Rust Core

- seed、noise、地质场、水文、侵蚀、沉积和语义识别；
- 产生并持久化 `NaturalTerrainSnapshot`；
- 执行工程地形和空间规则；
- 计算最终 heightfield、DrainageGraph、HazardLayer、BuildabilityLayer；
- 独立审计、拒绝或重试。

## 9. 验证标准

自然阶段至少审计：

- 高程、坡度、曲率和边界连续性；
- 河流从高处到低处，支流汇入主河，不能逆流；
- 流域覆盖率、河网密度、湖泊闭合和洪泛区连续性；
- 山脊/谷地连续性和数量；
- 沉积物质量误差、出口流量和海平面一致性；
- 生态/保育区不被默认建设；
- 同 seed 可复现，不同 seed 有统计变化但不破坏硬约束。

人类工程阶段额外审计：

- 每个 carve 有材料/排水/稳定性预算；
- 工程实体不穿越禁建水体，桥/堤/涵洞为合法例外；
- 最终坡度、建筑地基、入口路径和道路连续；
- natural snapshot 与 final snapshot 可差分回放。

## 10. 分阶段迁移路线（本轮不实现）

1. 冻结当前自然场与工程场格式，给自然场加版本和来源；
2. 增加宏观 relief masks 与 DrainageGraph 持久化；
3. 以流域/河谷派生洪泛和冲积地貌；
4. 增加语义地貌实体和 BuildabilityScore；
5. 将人类工程统一为有序 delta，不再由建筑逻辑直接修改自然底图；
6. 先在 512 m chunk 和 1 km/6 km 验证，再跑 6×10 km；
7. 增加自然统计 golden fixtures 和 seed 跨样本测试；
8. 最后让 Agent 读取报告并提出下一轮意图，不让 Agent 直接修几何。

## 12. 最终回答用户第二个问题

**可以，而且应该这样做。** 先生成自然地形不是“先做一个渲染背景”，而是先建立后续所有建筑、道路、水体和工程的事实基础。只要自然层输出版本化的高度场、水文图、灾害图、地貌语义和可建设性评分，Rust Core 就能在此之上生成道路、地块、建筑和人类痕迹；Agent 只需选择意图和参数。真正需要重构的不是把自然地形移到另一个 agent，而是把自然层变成 Rust Core 的独立、可审计阶段。
