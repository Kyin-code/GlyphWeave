## 3. 本轮检查方向与结果

### 3.1 房屋是否依据地表接地

**通过。**

建筑不再只使用中心点或水面 datum 作为地基高度，而是在 footprint 内逐米采样自然地形，取最高采样值作为最低接地高度。这样可以避免 footprint 内部高侧地形被房屋穿入。

生成式建筑随后通过 `rebase_buildings_to_surface()` 至少抬升到该高度；其地形 pad 只允许填高低侧，不允许把已有较高自然地面挖低。

实测 `grounding-check-32` 中所有抽查建筑均满足：

```text
baked footprint min == entity.world_y
baked footprint max == entity.world_y
```

抽查类别包括：

- `commercial_center`
- `school`
- `residential_block`

### 3.2 是否仍会为了海平面挖空地表

**通过。**

`terrain_height_with_geometry_carved()` 的普通生成 pad 已改为 fill-only 语义：

- footprint 内：`max(natural_terrain, pad_target)`；
- blend ring：仅当 pad 高于自然地形时填高；
- pad 不再把高地强制降低到实体中心高度；
- 水面 0 高程只用于水体 datum，不作为陆地建筑的默认高度。

因此，房屋低于高侧地表时会抬升房屋或填低侧，而不是挖掉高侧地面。

### 3.3 道路为何此前会出现异常下陷

发现并修复一个独立的通用几何问题：道路的 `width/depth` 是局部坐标尺寸，必须结合 `rotation_y_deg` 转换成世界 X/Z footprint。

此前 carve 逻辑按照“宽度大于深度”推断方向，导致：

- 0° 的东西向长路可能按错误方向扩展；
- `road-ns` 的 90° 道路可能使用错误的 carve 范围；
- 结果表现为道路旁地面被大范围错误压平或形成沟槽。

现在：

- 0°：local width → world X，local depth → world Z；
- 90°：local width → world Z，local depth → world X；
- 生成前统一执行 `normalize_spatial_semantics()`；
- 建筑、道路、自然对象 clearance 使用旋转后的 world-space half extents。

### 3.4 房屋与道路是否互相穿插

**通过。**

此前 waterfront 城镇的道路中心线与商业中心可能重叠。现已将 civic parcel 从道路中心线移到河岸道路侧方，并在最终生成后执行统一的道路/建筑/自然对象 clearance。

`grounding-check-32` 实测：

```text
roads = 8
buildings checked = 18
building-road overlaps = 0
detail-road overlaps = 0
detail-building overlaps = 0
```

### 3.5 树木是否在道路上

**通过。**

所有 planner 完成后统一执行 clearance，而不是只在早期模板阶段过滤。检查对象包括：

- `tree`
- `bush`
- `grass_clump`
- `rock`
- `fallen_log`

道路和 sidewalk 使用旋转后的真实 footprint；自然对象按自身 footprint 和安全边界检查。

`grounding-check-32` 实测：

```text
detail-road overlaps = 0
```

因此“树木在路上”这一类数据侧错误已经被挡住。

## 4. 新增自动化测试

本轮新增/加强：

1. `building_grounding_uses_the_highest_footprint_sample`
   - 检查建筑逐米 footprint 接地；
   - 检查 baked pad 不穿入建筑底部。
2. `generated_pads_never_excavate_higher_natural_ground`
   - 检查普通生成 pad 不降低自然高地。
3. `road_carve_respects_world_rotation`
   - 检查 0° 与 90° 道路使用正确世界 footprint。
4. `waterfront_civic_buildings_clear_their_access_roads`
   - 检查水岸公共建筑不会压道路中心线。
5. 既有 `generated_natural_details_clear_road_footprints`
   - 检查树木等自然对象避开道路。
