# Milestone C 最终目标与阶段衔接（v2，当前不派发实现）

日期：2026-09-08。**替代旧版将第二Agent立即派去做C的任务书。**当前两人都围绕A；B/C要求保留，不以完成A为最终完成。

## A→B→C

A：稳定可重复的Rust核心、固定合同/失败透明、稳定ID/存量、性能与大文件读取、全域HTML验证；完整质量gate可以保留逐条审批的B/C内容缺口，但不能新增工程/来源错误。

B：真实街区/聚落，不只是加楼数量。主次支道路、地块分割、退界、密度和高度分布、公共空间/设施、城乡农田竞争、区域形态profile。最终文化范围包括中国/美国/欧洲与日本/香港的研究要求；不能用国家标签+一个比例代替真实布局依据。现实案例的证据等级与参数来源仍需复核，研究文档存在不代表生成器已实现。

C：自然地貌→人类建设→自然与工程相互影响闭环，覆盖最大6×10km、城市/农村/荒野。Agent表达背景/用途/形态/约束；Rust规划、生成、判定与审计；HTML不得发明未在Rust中的对象/地形。

## 后续派发原则

A验收后，以一条可验证的自然—工程小场景建立接口，再推广到B/C全域；小场景只是开发步骤，不替代最终范围。Terra可承担跨模块数值/工程合同，DeepSeek可承担范围明确的区域profile工具和独立验收；最终分配根据A首批表现调整，不假设模型能力。

具体C写入锁、验收数据集、性能/精度界限在开工前冻结；当前没有授权任一worker修改自然核心或部署新侵蚀库。总控只负责规划、评审、集成验收。
