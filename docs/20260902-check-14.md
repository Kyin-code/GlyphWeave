# GroundingSpec 高度契约验收报告（第 14 次）

- **日期**：2026-09-02
- **目标**：统一 entity/landmark 的 pivot、底部偏移、道路路床偏移、terrain carve 和 baked audit 的高度语义。

## 已完成

新增 `GroundingSpec`：

```text
pivot: bottom | center
bottomOffsetM
roadbedOffsetM
toleranceM（默认 1.0m；world_y 仍为整数期间的量化容忍）
```

已接入 `EntityInstance`、`LandmarkSpec`、rules placement source、terrain carve 和 baked audit。

`world_y` 的定义为 **实体 pivot 的世界高度（米）**；接地高度为：

```text
world_y + pivot offset + bottomOffsetM + roadbedOffsetM
```

`pivot=center` 减去 entity 高度的一半，`pivot=bottom` 不额外偏移。

## 验收清单

- [x] GroundingSpec 有强类型和默认值。
- [x] 非有限高度偏移会在 Manifest 校验中失败。
- [x] terrain carve 使用 `ground_height_m()`。
- [x] baked audit 对 `onGround=true` 实体比较最终 baked ground 和实体接地高度。
- [x] `toleranceM` 显式处理 world_y 整数米与 0.25m terrain 的量化差。
- [x] rules 重放保留 source grounding。
- [x] bottom/center pivot 均有单元测试。
