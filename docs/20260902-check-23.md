## 2. 本轮修改

### 2.1 新增 `WorldIntent::validate()`

文件：

```text
G:\difyllmwiki\GlyphWeave\bevy\crates\core\src\intent.rs
```

校验内容：

- 名称不能为空；
- `scene_id` 不能为空；
- 场景尺寸遵守通用地图约束：
  - 最小 `512m`；
  - 最大宽度 `6000m`；
  - 最大深度 `10000m`；
- `River` terrain 必须使用 `River` water intent；
- `Lake` terrain 必须使用 `Lake` water intent；
- 冲突时返回结构化错误，而不是继续生成。

### 2.2 CLI 入口接入语义校验

文件：

```text
G:\difyllmwiki\GlyphWeave\bevy\crates\cli\src\main.rs
```

以下命令现在都会先执行 `WorldIntent::validate()`：

```text

glyphweave intent compile INTENT.json MANIFEST.json
```

因此 Agent 或人工编辑的 Intent JSON 即使能通过 JSON schema，也必须先通过语义约束才能编译。

## 6. 验收判断

当前链路已经具备三层保护：

```text
自然语言草案缺字段
    -> IntentDraft 拒绝

Intent JSON 结构未知字段
    -> deny_unknown_fields 拒绝

Intent 语义冲突或越界
    -> WorldIntent::validate() 拒绝

合法 Intent
    -> compile Manifest
    -> generate-world
    -> scale-audit / quality-report
```

这使 Agent 可以安全地负责自然语言理解，而不会把不完整或矛盾的猜测直接写入地图生成管线。
