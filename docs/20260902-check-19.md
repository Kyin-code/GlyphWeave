# 生成参数可用性与空间语义继续修复（第 19 次）

- **日期**：2026-09-02
- **前置提交**：`3c09bdb feat(worldgen): formalize world data contracts` 已推送至 `origin/main`。
- **目标**：继续处理真实 baseline 暴露的问题，区分“参数未应用”与“参数应用后偏差”，并让新空间字段开始被生成器和 HTML 使用。

## 已完成

### 1. LandUseProfile 适用性显式报告

`quality-report` 新增：

```text
landUseProfileApplied: true | false
```

当前生成器只在无结构化水体、且 `naturalOnly=false` 时执行 profile-driven land-use pass。

因此：

- `naturalOnly=true` 的内蒙古草原，不再错误地被判为“rural 参数偏差”；
- 深圳湾等 structured-water 场景，不再把未执行的 land-use profile 当作已执行后失败；
- quality-report 会明确警告 profile 当前未被执行，而不是输出误导性的面积偏差。

这不是隐藏问题，而是把问题从“假参数失败”改为“真实能力缺口”：**水体场景还没有 profile-driven land-use generator。**

### 2. 显式 rotation 与自动 building front anchor 开始使用

`EntityInstance::normalize_spatial_semantics()` 现在：

- 将历史 `road-ns` / `north-south` ID 约定规范化为 `rotationYDeg=90`；
- 对没有 authored anchors 的建筑自动生成 `front` anchor；
- front anchor 带明确 `direction` 和 `target=road`；
- HTML adapter 优先读取 `rotationYDeg`，只在旧数据缺字段时保留 entity ID fallback。

### 3. 基线更新

四份真实 baseline 已更新 `qualityStatus`、warnings 和 `landUseProfileApplied`。
