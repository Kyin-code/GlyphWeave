## 4.2 场景构图：不通过（P0 视觉问题）

### 默认战略图

战略图能够表达水域、两侧陆地和桥的平面关系，但信息极度压缩：

- 水域是一整块蓝色矩形；
- 两侧陆地主要是纹理色带；
- 桥只是一条横向浅色矩形；
- 新增购物中心、写字楼、夜市、山体等类型没有有效的战略图图例或符号层级。

因此战略图能作为“数据分布调试图”，不能作为“深圳湾空间叙事图”。

### 默认 2.5D / `?view=near`

画面几乎被桥体填满，出现以下问题：

- 桥体距离过近，地面、水体和岸线无法同时观察；
- 桥体太暗，桁架与下层结构混在一起；
- 缺少桥头、远岸山体、北岸建筑的参照物；
- 用户很难判断桥是否跨在水上，容易产生“只有一条路面”的错觉。

### `?view=skyline`

全景视角中，整个场景被压成接近地平线的一条薄片：

- 天空占据绝大多数画面；
- 地面起伏几乎不可见；
- 物体高度比例被压缩；
- 山体、建筑、桥、水体没有形成前中后景。

该视角目前不适合作为默认展示，也不适合作为素材质量评估视角。

## 4.3 地形表现：不通过（P1）

当前地形有噪声、PBR normal/roughness 和语义材质代码，但从截图看，地形的“形”仍然不够：

- 地表大面积保持平直；
- 缓坡、岸线过渡和远岸山体没有形成明显的高度层次；
- 地形纹理变化容易被误认为颜色噪声，而不是地貌起伏；
- 山体实体与地形高度场仍是两个视觉系统，山体更像摆在地面上的模型。

这里要区分：

- **材质变化**：代码已有；
- **几何起伏**：当前画面仍不足；
- **自然地貌连续性**：当前未达到可展示水平。

后续应优先改善通用地形生成/烘焙和地形视觉采样，不应只继续提高纹理噪声。

## 4.4 草地表现：不通过（P1）

代码中确实存在 GPU instanced grass、草密度参数和湿润度/坡度/扰动筛选，且发布目录文件已同步。但实际截图不能证明草地已经达到明显效果：

- 远景中草主要表现为细碎黑点或颜色颗粒；
- 草叶的覆盖区域与底色差异不足；
- 草地没有形成连续的草甸边界；
- 草、灌木、树木之间的尺度层级不够明显；
- 近景默认视角没有给出足够大的草地观察区域。

因此“草渲染代码已接入”不能等同于“草地视觉验收通过”。当前应判定为：**代码接入通过，视觉效果不通过**。

## 4.5 视觉分发复杂且不统一：条件通过（P1）

当前仍存在以下分发路径：

- landmark renderer；
- entity renderer；
- legacy asset prototype；
- `makeCoastalFeature()`；
- vegetation instancing；
- bridge generic fallback。

这会造成同一种类型在不同来源下可能有不同外观、接地方式和 bounds。尤其是新增海岸类型目前只在程序几何中有表现，尚未建立统一的 `EntityVisualContract`。

建议后续将视觉合同统一为：

```text
kind
renderClass
asset / proceduralRecipe
width / depth / height
rotation / pivot
bounds
collisionClass
materialTheme
```

## 5. 素材与逻辑问题的区分

本次复核结论不是“所有问题都是素材差”，而是分为两类：

### 主要由素材/视觉构图造成的问题

- 建筑像盒子；
- 山体像锥体；
- 夜市、广场、滩涂不可识别；
- 桥体结构层次不清；
- 草地看起来像噪点；
- 全景像一条薄片。

### 仍需继续检查的渲染逻辑问题

- 2.5D 默认焦点不应只锁定桥中央；
- 桥、水面、道路的深度排序需要按统一的世界高度和材质透明策略处理；
- 生成实体与 landmark 的重复/跳过策略需要统一；
- 实际 mesh bounds 应与规则 footprint 保持一致；
- 地形高度场需要在视觉上提供可验证的起伏，而不是只提供数据；
- vegetation 的密度、裁剪和道路排除需要在多个视角验证。

## 6. 建议修改顺序

### 第一优先级：先重做“核心可识别素材”，不要继续增加词条

建议先只改以下 6 类：

1. **桥**：提高钢结构明度，区分桥面、桁架、桥墩、下层结构，增加桥头过渡和可见净空；
2. **道路**：增加路缘、肩带、车道线和桥头连接，明确道路不会被草和地表装饰覆盖；
3. **地形**：增加低频高度起伏、岸线缓坡和远岸山体，而不是继续叠加颜色噪声；
4. **建筑组**：购物中心、写字楼、便利店各自建立明显轮廓，不再只使用“盒子+色条”；
5. **山体组**：用多层低多边形体或高度场融合替代单一 Cone/Sphere；
6. **草地/湿地**：先保证一块 100m 以上连续草地可见，再调密度、颜色和层级。

### 第二优先级：统一视觉合同

将 landmark、generated entity、asset prototype、procedural feature 汇聚到统一分发函数；所有可见物体必须使用同一套：

- world transform；
- pivot；
- rotated bounds；
- ground policy；
- material theme；
- collision class。

### 第三优先级：重新设计默认 2.5D 镜头

默认画面应该至少同时看到：

- 一段桥；
- 一侧桥头道路；
- 水面；
- 北岸或南岸地形；
- 至少一种建筑或自然物。

桥体专用检查可以保留 `?view=bridgehead`，但不能让桥中央特写成为唯一默认体验。
