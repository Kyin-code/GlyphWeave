# Entity / Landmark 空间语义验收报告（第 16 次）

- **日期**：2026-09-02
- **目标**：让实体和地标不再只是中心点和尺寸，保留方向、锚点、grounding 和 bounds。

## 已完成

`EntityInstance` 与 `LandmarkSpec` 新增：

- `rotationYDeg`；
- `grounding`；
- `anchors`；
- `bounds`。

新增自动 bounds 规范化；rules re-placement 会保留 source rotation、grounding、anchors 和 bounds。
