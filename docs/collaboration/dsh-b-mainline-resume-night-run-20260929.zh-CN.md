## 3. B完整工作清单、实现顺序和验收结果

### B01：真实地块、建筑、院落与入口闭环

目标：parcel不是建筑周围一个标签，而是有明确归属与实际使用的空间。

必做：
1. 可配置前/侧/后退界与完整地块几何，支持现有四朝向；显式建筑尺寸优先，profile只补缺省。
2. 区分道路边缘退距、parcel内退界、入口净空，不用一个setback字段混代。
3. 建筑footprint在parcel内，parcel不越界、不重叠、不占保护/水域；合法共享边界不能误判非法碰撞。
4. 庭院、铺装、入口通道真实生成，持久化为有来源的几何/SurfacePatch；reserved yard不能算realized。
5. 门→通道→实际道路/公共步行网络相连；固定门/固定接点不能偷偷搬走。
6. natural/final分开；支撑、坡度、保护、毫米级几何约束保持。已接受结构工程只按其已证能力复用。
7. parcel/building/yard/通道/剩余地面积守恒，不用建筑楼面面积充土地面积。

验收：512m真实输入的请求/候选/实现/拒绝、入口访问与实际土地账本可复算；四朝向、非零origin、邻地冲突、院落被删、固定门堵塞有负例。包含非零业务实现，不能空网格全绿。保留不属本切片的全图缺额，不假称B整体通过。

### B02：需求驱动的分层道路与供给

必做：

4. 候选按未满足住宅/设施/临路长度/可建parcel/农田接入收益排序；计划收益与最终实现收益分开。
5. 同层真实接点连接；无依据的跨水/立交/桥隧不能视为合法直连；固定路/已有身份不被静默删除或移动。
