# 道路设计高程、跨线结构与独立碰撞审计（2026-10-23）

## 结论

黑色大块与弯道路面破碎的主因不是材质颜色，而是道路中心线与最终烘焙地形
不属于同一条工程链：

- r155 的 2,588 个路线中心线采样中，2,451 个设计面低于最终地形；
- 最大埋深 14.716m；
- 部分 8m 路实体在规划历史中被单侧拓宽到 32m，但 HTML 仍按路线计划的
  8m 绘制，导致地形、碰撞和可见路面不一致。

本轮以 Rust 路线计划重新作为宽度与纵断面真源，未通过抬高渲染面掩盖问题。

## 实现

### 1. 任意朝向路线纵断面

- `GroundingSpec.routeGrade` 发布每个路线分段的起止米制坐标与设计高程；
- 弯道、斜街和不等宽道路不再受旧 `RoadProfile` 只能横平竖直的限制；
- 地形组合在道路 flat top 内允许真实挖方和填方；
- 同一位置的道路 centerline/footprint 优先于其他道路的过渡肩带。

### 2. 交叉冲突与高架

- 高差超过 1.2m 的相交、共线重叠或宽路面 footprint 重叠，自动在高位路线
  发布 `overpass`；
- 低位路线继续拥有自己的挖方、路面与碰撞；
- 高架段不再产生地面 carve；
- 相邻高架 span 合并，避免逐 2–4m 段落生成重复桥墩记录；
- r169 共 41 个合并后的跨线 span。

### 3. 路线宽度同步

规划历史不再暗中拓宽 `generated.route-evolution.*` 实体。该拓宽只改
EntityInstance 的深度，不同步路线计划、HTML 与碰撞，属于双重真源。
后续若要支持区段拓宽，应先升级为路线级 segment width，再同时消费到 carve、
可见横断面和碰撞。

### 4. 路面语义与碰撞

- route strip 作为连续可见表面；
- 每段 solid OBB 保留为独立碰撞代理，但不再逐段显示重叠盒面；
- 道路走廊表层分类为 stone/asphalt，复杂路口不再露出草地色块；
- HTML 增加同高合并口的铺装补面；跨线交叉不生成单层路口盖面；
- 沥青颜色从近黑灰调整为日光下可识别的灰色。

## 仍未完成

1. 复杂汇流口的 Rust union polygon 尚未实现；当前 HTML 以同高补面过渡，
   不得把补面当作碰撞或地形真源。
2. 剩余 16 个超过 0.75m 的道路中心线采样仍需逐点定位，优先处理
   `urban-grid-v420` 与 `old-town-west-street` 的局部冲突。
3. 高架桥目前使用路线连续带、桥墩和独立碰撞，但尚未生成桥面护栏、排水与
   桥头挡墙模型。
4. 车道数、中央隔离带和人行道宽度已由 Rust 横断面发布；实际车道级碰撞和
   车辆通行规则仍属于运行时扩展，不在 B 里程碑假称完成。
