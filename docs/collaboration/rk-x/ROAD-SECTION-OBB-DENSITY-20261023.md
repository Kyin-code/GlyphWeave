# 道路断面、OBB 与中心建筑密度修复（2026-10-23）

状态：**代码已修复并完成 r192 完整烘焙；scale-audit 通过，最终实体碰撞审计通过。仍有 24 栋建筑没有完整步行入口，质量门保持 warn，不能签收。**

## 1. 本轮直接回应的四个问题

### 1.1 中心建筑密度与固定尺寸

- 删除预览端重复绘制的一整套未旋转 `settlementEvolutionPlan` 盒子；此前每栋真实建筑上还叠着一个轴对齐 Box，既伪造了“固定大小房屋”，也掩盖了真实 OBB。
- 建筑原型不再把旧城住宅限制在统一浅进深：
  - 混合住宅进深 20–34m；
  - 办公塔楼进深 24–44m；
  - 旧城排屋进深 16–32m；
  - 临街商业进深 18–32m。
- 临街地块按时代保持不同街墙节奏。旧城以单模块窄临街为主；更新区少量 2 模块组合；新城最多 3 模块。组合模块会同时推进下一个地块游标，避免用放大盒体制造假接缝。
- 街廓内部填充由 16m 节奏改为 12m，并允许住宅、办公、商业和零售需求进入内部地块，不再把内部建筑强制降为零岗位的纯住宅附属物。

### 1.2 道路等级、车道、高速断面和独立碰撞

- `RoadDesign` 增加 `shoulderWidthM`。先按总路权分配车道、中央隔离、路肩和人行道，再由断面决定表现资源。
- 6 车道快速路由 6×3.5m 车道、3m 中央隔离、两侧 1.2m 路肩和 2.5m 人行道组成，总占用 31.4m，限制在 32m 路权内。
- 4 车道主干路总占用 22.4m，限制在 24m 路权内。
- HTML 不再把 2.5–3m 人行道画到道路 OBB 外面。车行道、路肩、人行道、车道线、中央隔离都位于同一总路权内。
- 道路碰撞仍使用独立实体 OBB 链，不从可见贴图反推；碰撞宽度使用完整路权。
- 删除按“附近路线采样对”生成路口盖面的逻辑。旧的近似合并会为同一条长走廊生成上千个重叠圆盘，r178 实测 1,156 个 junction mesh，吞掉车道线和路角。现在仅对真实中心线相交生成去重盖面，半径由实际相交道路宽度决定。
- `makePolylineRibbonGeometry` 继续消费 Rust 发布的 `designHeightM`，不从左右地形分别重采样；因此弯道不会因地形左右高低被扭成薄片。

### 1.3 房屋旋转、碰撞与楼内绿植

- 修正 `oriented_footprints_overlap` 的旋转符号。旧 SAT 使用镜像轴，和 `OrientedFootprint::contains`、Three.js 的实际变换不一致；同角度测试因此长期误通过。
- 新增非对称回归：建筑 `-135°` 与道路 `45°` 的相交/分离两个方向都必须判对。
- 修正后重新烘焙，规划期真实拒绝原先被漏过的建筑/道路 OBB 相交；r192 最终实体审计为建筑-建筑 0、建筑-道路 0、建筑-细节 0。
- 预览端植被过滤同时检查道路和建筑 OBB，Rust 审计仍是最终真源。
- 店面前墙花箱从墙体中心移到立面外的公共临街侧，避免半个绿色 Box 进入室内。
- 现代住宅基座不再比实体 OBB 各向外扩 0.4m。
- `residential_tower` 和 `makeCoastalFeature` 的根旋转补齐为单次权威旋转，避免未来出现双重 yaw。

### 1.4 自然与参考

- `REFERENCE-AUDIT-20261023.zh-CN.md` 已记录香港规划署、CEDD、Highways Department、HFC、NACTO、Quaternius、Three.js 地形/水面案例及适用边界。
- 本轮不把自然山体、水体、建筑退化为材质占位；自然地形、河床/水面、林缘和地貌接口继续由 Rust 发布，HTML 只消费。
- 街景相机优先搜索中心 230m 内、远离多路交叉且临街商业/住宅密度高的路段，避免默认镜头落在空旷大路口。

## 2. 分块连续性根因

此前同一 fill ring 在左分块被烘焙、右分块却被 chunk-local carve 预过滤掉，x=512 两侧出现 **4.643m** 人为断崖。

修复：所有分块使用同一份全局 carve 集合；`CarveIndex` 在单元格查询时只返回附近候选。预过滤 AABB 不再参与生产烘焙。

r192 scale-audit：

- 最大跨分块高度差：**1.071m**；
- 上限：4m；
- 状态：**pass**。

市场选址也增加了最终中心点到 seam 的二次检查，防止候选节点安全、但侧移后的市场 footprint 跨缝。

## 4. 仍未完成

1. 24 栋建筑无完整步行入口；不得把 quality-report 的 warn 改写成 pass。
2. 旧城中心覆盖率仍低于中环样本。下一轮应继续做真实街廓组合体/庭院地块，而不是简单增加需求数或把碰撞盒缩小。

4. 道路碰撞目前仍是分段实体链；可见路面是连续 ribbon，第一人称长期行走时还需按纵向坡度插值，不能只用每段端点最高值。
5. 自然山水仍需接入地貌骨架：山脊/谷地/汇水、岸线湿边、河床坡降和林缘，不应只由噪声散布。
