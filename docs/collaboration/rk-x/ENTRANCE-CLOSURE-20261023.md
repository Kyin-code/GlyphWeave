# 建筑入口闭环（2026-10-23）

状态：**r201 完成；scale-audit pass，quality-report pass，最终实体审计 pass。**

## 1. 修复内容

本轮没有放宽入口坡度、碰撞、道路或地形门限，而是修正三处入口语义：

1. 推广的临街楼梯此前把“立面旁边的已烘焙地形”当作起点，抹掉了建筑门槛与道路之间的真实高差。现在从 `building.ground_height_m()` 起算。
2. 长楼梯按最多 22m 一段拆分；整条连接可以跨越多个合法梯段，每段高度仍受 8.5m stair contract 约束。
3. `rejectable_candidates` 以前只要任意一个锚点失败就会把建筑删掉。现在只有**所有入口都失败**的未受保护生成建筑才会被剔除；前门失败但侧门成功不再触发误删。
4. 可选梯段无效时，不再提前把入口判成 `stair_connection_invalid`；如果直接入口本身可达，仍允许使用直接路线。
5. 临街建筑发布 `rear` 服务入口。局部平台或后方道路高于临街道路时，建筑可以从背面接地，不再被强制补一条穿越街区的高差走廊。
6. `frontage::validate_entity` 接受 `rear` 作为合法服务入口；正面锚点仍保持第一个，继续控制可见主立面和渲染朝向。

建筑仍遵循“数量是结果，不是常量”：r201 有 18 栋无法建立任何合法步行入口的建筑没有进入最终世界，而不是悬空或伪造入口后强行保留。

## 3. 纪律

- `entrance_step_requires_engineering` 仍然是一个具名拒绝，不是通过条件。
- 只有完整步行路径（坡度、净空、水体、道路端点、地形连续性）全部通过时，建筑才计为 connected。
- 入口修复不得改变建筑 OBB，不得移动道路，不得修改地形阈值或审计容差。
- 后续增加中心密度时，必须先提供合法的入口/平台/侧门，而不能恢复无入口建筑。
