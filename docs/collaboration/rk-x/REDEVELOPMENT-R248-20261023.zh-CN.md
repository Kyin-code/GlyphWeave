# 城市重规划与设施替换 r248

## 规则

大型公共设施在找不到空地块时，可以对普通城市建筑进行成组重规划。每个
被替换建筑计算：

```text
weight =
  0.35 * age
  + 0.25 * low-density
  + 0.18 * poor-access
  + 0.14 * centrality
  + 0.08 * low-rise
```

- 旧城权重最高，更新带次之，新建区较低；
- footprint 小、入口条件差、中心地价高和低层建筑更容易被更新；
- 保护对象、历史街区原型、市场、学校、医院、教堂、寺庙及 civic 设施
  返回不可替换；
- 一个设施最多清理 12 个普通建筑 Owner；
- 医院和体育场的公共收益阈值略低，其他设施要求更高平均权重；
- 替换全过程不缩小 OBB、不改变道路或水体合同；
- 替换后重新计算住宅、岗位、零售、服务需求、可用地块和中心密度曲线。

## 香港 r248

- 需求：学校 1、诊所 2、医院 1、教堂 2、社区中心 2、体育中心 2；
- 实际发布：每类需求全部物化；
- 10 组重规划决定，记录设施 ID、被替换建筑 ID 列表、平均权重、模型和原因；
- 4,488 实体，7 市场，15 分钟鲜食覆盖 100%；
- 入口断连 0，建筑/道路/细节碰撞 0，悬空/穿地/落水 0；
- `scale-audit=pass`、`quality-report=pass`。

重规划使规划住宅/岗位需求出现 1,541 户和 7,947 岗位缺口。这个缺口保留在
`settlement-evolution-plan.json`，没有通过增加虚拟住户或缩小碰撞盒补齐。
后续应通过更高层公共设施或混合用途裙房恢复容量，而不是把缺口隐藏。

## 未列入香港本轮的设施

体育场仍保留 Core 合同，但 1km 核心切面没有为其配置硬性需求。体育中心
已物化 2 座；未来在土地更充裕的新城或大型校园切面启用体育场。
