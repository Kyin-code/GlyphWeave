# 自然地貌到现代城市：生成链重构审核稿

状态：**待项目负责人审核，未授权实现**

日期：2026-10-21

## 0. 结论

现有生成链的问题是顺序和语义错误，不是楼房模型不够多：

1. 当前道路先由固定网格选出基础边，再围绕道路生成 frontage；
2. frontage 请求显式写建筑 `count`，容易把“需求”变成“必须凑数”；
3. 中心距离目前接近圆心裁切，不能表达可达性、商业竞争和历史阶段；
4. 聚落没有先从水源、谷口、渡口、可建设地和道路交汇中自然出现；
5. 新老城差异仍偏“同一套地块 + cohort 材质”，不是保留、填充和更新的过程。

建议的新主链：

```text
纯自然世界
→ 人类初步路径
→ 沿谷/梁/渡口形成道路工程
→ 聚落种子涌现
→ 旧核心生长
→ 扩张与工业化
→ 现代新区/更新区
→ 功能设施与生鲜市场服务场
→ 联合审计与完整烘焙
```

目标是生成“经历多个建设阶段后的静态结果”，不是完整人口/经济史模拟。

## 3. 跨样本抽取的七条逻辑

1. 交通与自然先于建筑；建筑是可达地块的后续填充。
2. 建筑数量是需求、地块容量和约束的结果，不是预设完成数。
3. 中心不是唯一圆心；轨道站、市场、教堂/寺庙、学校、港口和桥头也可以是次级中心。
4. 老城不是低质新城：老城保留细街网、小地块、混合底商和历史节点。
5. 郊区、旅游、放牧、种植不是低密城市，各自有道路、地块和设施逻辑。
6. 商业是网络：底商、便利店、菜场、超市、批发与旅游商业服务不同人群与容量。
7. 更新必须是保留、拆合、填充、重建的显式操作，不能用材质换新旧。

## 4. 新生成编排

### N0 自然世界

输出地质、地貌、山脊谷地、坡度、曲率、河流湖泊、湿地海岸、水位流向、土壤、
气候、生态群落、灾害与资源。此时没有道路、建筑、农田或人工构筑。

闸门：

- `humanTraceCount = 0`；
- 高度、水面、岸线和 chunk 边界连续；
- 同一 seed 重复得到相同自然快照；
- 通过战略图和自然近景验收后才进入下一阶段。

### H1 人类初步路径

从谷口、渡口、山坳、泉水、湖岸、海岬、林缘、农地和资源点建立候选节点。
路径使用有曲率的地形成本搜索，代价包括坡度、转弯、水深、湿地、林地、侵蚀、
洪泛和桥隧成本。

道路不以直线为默认；能沿谷线、等高线或山梁时优先顺应地形。过水必须有桥梁、
堤道或涵洞结构，或者明确拒绝。

### H2 道路网络和地形工程

- 区域连接/港口/铁路/城市核心产生 arterial/collector；
- 聚落内部产生 local/alley/path；
- 农田、牧场、林场有各自道路类型；
- 路口通过显式端点和真实交汇几何连接；
- cut/fill/bridge/culvert 都作为有版本的工程操作。

### S1 聚落种子

聚落数量不预设，由以下分数决定：

- 水源可靠性和洪水风险；
- 可建设面积、坡度、排水；
- 渡口、桥头、港口、道路交汇；
- 土壤、牧场、木材和资源；
- 风景、交通、防御和与既有聚落的互补。

未达到可建设/接入阈值的候选只进入拒绝报告，不生成“凑数小屋”。

### S2 建筑涌现

```text
住户/就业/服务需求 + 地形和地块容量
→ 用途和强度预算
→ 地块拆分和可建面积
→ 建筑类型、体量、入口
→ 实际建筑数量（结果）
```

普通建筑不再要求“每个请求必须完成 N 栋”。`householdsTarget`、就业岗位、
商业面积或摊位容量是需求；建筑数量是容量与地块条件的结果。

不能满足时输出 `unmetDemand`、原因和替代候选，不复制建筑、不缩小合同塞入。
固定数量只用于明确地标或明确必需设施，并且仍需通过空间合同。

### S3 建设阶段与新老城

| epoch | 典型空间结果 |
|---|---|
| founding | 渡口/路口/寺社/市场旁的小聚落，窄路小块、混合使用 |
| old-core | 细街网、连续街墙、小店铺、市场/教堂/市政/老宅 |
| expansion | 沿谷/道路扩展，学校、住宅组团、铁路/仓储 |
| industrial | 铁路、仓库、厂房、工人住区、缓冲带 |
| modern-new | 站点/快速路周边，大块地、写字楼、塔楼、超市和公园 |
| renewal | 保留部分旧路和建筑，拆合地块，加入新用途与公共空间 |

每个对象保存 `constructionCohort`、父对象、保留/修改/拆除/新建操作和来源。
新老城是旧骨架经过阶段更新的结果，不是两个模板拼接。

## 6. 生鲜市场辐射模型

### 设施层级

- 社区菜场/湿货市场：老核心、住宅街区，摊位/营业面积为容量；
- 邻里超市：普通城区和站城混合区，建筑面积/冷藏能力为容量；
- 大型超市：新区/郊区走廊，停车和配送纳入约束；
- 周期性市场：乡村旅游/广场，记录开放时段；
- 批发/集散市场：城市边缘、铁路/港口，服务农业生产和物流。

### 公式

对需求单元 `i` 和设施 `j`：

```text
吸引力 A_ij = capacity_j * quality_j * exp(-beta_mode * travel_time_ij)
需求分摊 P_ij = A_ij / Σ_k A_ik
设施负载 L_j = Σ_i demand_i * P_ij
局部供给密度 rho_i = Σ_j capacity_j * exp(-beta_mode * travel_time_ij)
缺口 deficit_i = max(0, demand_i - rho_i)
```

- `travel_time_ij` 从真实步行/道路/公交网络计算，不用直线距离；
- 步行、骑行、车行、公交使用不同衰减参数；
- 市场之间通过分母竞争，重叠服务自动降低边际价值；
- 每次放置后重算负载，防止市场互相挤死；
- 不满足最低需求的候选不放置，记录 `under_minimum_demand`。

初始启发式范围：

- 高密旧核心：步行 5–10 分钟，网络距离约 300–700m；
- 普通城区：步行 10–15 分钟，约 600–1000m；
- 新区/郊区：以邻里中心和 10–15 分钟公交/车行为主；
- 乡村：周期/集散设施按 3–8km 车行和人口阈值；
- 旅游区：居民与游客需求叠加，不能只看常住人口。

这些是待标定参数，必须保留“网络时间 + 容量 + 竞争 + 需求”的模型结构。

## 9. 分阶段实施计划

### Phase 0 纯自然

冻结自然快照，0 人类实体，完成地形/水系/生态/chunk 连续审计。

### Phase 1 自然道路

自然种子生成非直线道路；记录曲线半径、断面、桥梁/涵洞；与旧网格做 A/B。

### Phase 2 聚落涌现

聚落数量由水源、可建设面积和道路接入决定；允许 0 个，禁止凑数建筑。

### Phase 3 容量建筑

按住户、就业、商业面积和地块容量生成；建筑数量成为结果；缺额具名持久化。

### Phase 4 新老城

依次执行 founding/old-core/expansion/industrial/modern-new/renewal；记录保留、
拆合、填充和新建操作。

### Phase 5 场景与市场

郊区、旅游、放牧、种植分别使用独立规则；市场按服务场和容量布局，生成
辐射密度诊断图。

### Phase 6 全链验收

- 自然图、战略图、旧城/新城近景、市场辐射图分别截图；
- 跨块道路/水岸/聚落连续；
- 入口可达、地面贴合、水体和保护区不破约；
- 每个阶段有独立 hash；
- `quality-report warn` 不得被解释为视觉完成。

## 10. 审核拍板点

1. 是否采用“纯自然 → 路径 → 聚落 → epoch”新主链？建议：是。
2. 是否把普通建筑 `count` 降级为需求/容量结果？建议：是。
3. 是否允许聚落数量为 0 或很少，禁止每个候选点凑房？建议：是。
4. 首个综合样例是否用 1km 做“谷地核心 + 旧城 + 新区 + 郊外边缘”，再用
   512m 做近景细节？建议：是。
5. 生鲜市场是否使用网络 5–15 分钟 + 容量/竞争，而非统一半径？建议：是。
6. 48 城是否仅作为参数先验和关系机制，不做整城复制？建议：是。
7. 第一版是否接受“多 epoch 的静态结果”，不做完整人口经济模拟？建议：是。
