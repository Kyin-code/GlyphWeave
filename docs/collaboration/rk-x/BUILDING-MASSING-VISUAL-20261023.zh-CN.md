# 建筑体量、旋转与可见碰撞复核（2026-10-23）

## 样本对照

48 城核心样本的建筑数量中位数为 410，p75 为 942；当前 r178 为 374 栋，
数量已接近样本中位数。中心 150m 为 71 栋，若按 1km 样本中位数均匀折算，
期望约 29 栋，当前约为 2.4 倍，说明“中心数量不足”不再是唯一问题。

当前主要短板是单体 footprint：

- 当前中位 footprint 约 93m²；
- 香港中环样本的平均单体 footprint 约 736m²；
- 当前中心 150m footprint 为 6,787m²，仍明显低于高密度样本。

后续不能继续只增加 6m 宽小盒子，必须支持 250–700m² 的临街组合体、裙房和
第二排内院地块。

## 本轮修改

### 1. 低层住宅不再固定切 2×3

旧渲染器无条件把每栋低层住宅切成六个微型小屋，导致：

- 6×10m 的合法住宅被画成六个不现实的小盒子；
- 相邻建筑虽通过 Rust OBB 碰撞，但屋面和基座可能视觉相交。

现在按 footprint 自适应：

- `<12m` 宽只画一个主体；
- `12–20m` 宽画两列；
- `>=20m` 宽画三列；
- 只在 `>=20m` 深时增加第二排。

#### 2. 可见几何不越过权威 OBB

- 坡地基础和建设年代基座不再向四周额外扩张 0.6m；
- 高层接触阴影从接近 1.44 倍 footprint 收缩到 1.05 倍；
- root yaw 继续严格使用 Rust `rotationYDeg`；
- 街面翻转仍只作用于子节点，不改变碰撞 OBB；
- 建筑、道路、草木碰撞继续由最终实体审计验证。

### 3. 回归尝试与撤回

尝试过把临街地块扩为双模块、增大内院组合体并扩大内院采样。结果：

- 总建筑数从 374 降至约 320–346；
- 150m 内 footprint 没有提高；
- 部分内院入口全部断开。

因此没有把该实验提交为默认规则。放大体量必须与“组合地块获取、入口可达性、
道路 support 冲突”一起实现，不能只放大盒体。

## 下一步

1. 在 roads-first 阶段先预留 2–3 个连续临街模块，供 250–700m² 组合体使用；
2. 同一地块允许裙房、塔楼与内院，不把一个地块拆成多个固定住宅盒子；
3. 对入口失败建筑执行“桥接平台/合法侧门/拒绝”三选一，不得标记 pass；
4. 完成后重新计算 100/150/200m 的建筑数量、footprint 和 10/15 分钟服务覆盖。
