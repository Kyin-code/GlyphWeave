# 街景相机：从建筑质心转向真实道路轴线

日期：2026-10-21
状态：HTML 预览修复完成；城市密度仍为 `warn`。

## 1. 缺陷

`?view=street` 原先用全部住宅、店铺和市场的全局质心作为焦点。香港中环
1km 切面里存在多个分离聚落，全局质心落在聚落之间的草地，运行画面只能看到
楼体和草坡，看不到道路、临街店面或市场。相机虽然可交互，但默认构图不能作为
街景验收。

## 2. 修复

街景焦点改为本地商业热点：

- 市场权重 6、店铺 5、公共广场 4、住宅街区 2.5、普通住宅 2；
- 90m 内对相邻城市实体做距离衰减；
- 46m 内存在道路时增加道路权重；
- 从热点寻找最近真实道路，按该道路 `rotationYDeg` 建立沿街前向；
- 相机放在道路轴线后方，目标点落在前方 58m，形成沿街纵深。

这只改变 HTML 相机和候选焦点，不修改 Rust Core 的实体、道路或土方数据。

## 4. 视觉结论

结论：`warn`。

原因不是相机空屏，而是城市表达仍不足：

- 街区之间保留大量草地，现代城市连续性不足；
- 建筑仍是体素占位体，没有足够立面分段与连续街墙；
- 道路在街景中可见但偏窄，地面材质与路缘细节仍弱；
- 新老城需要靠街网、地块尺度、公共空间和拆合关系表达，不能只靠楼层高度。

因此该修复解决“看不到街道”的构图错误，不代表城市密度验收通过。
