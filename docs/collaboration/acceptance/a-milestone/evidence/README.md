# Milestone A compact evidence archive

Milestone A stable foundation is accepted; world quality is still **fail**.

The parent acceptance document explains scope and retained issues. This directory preserves selected original evidence bytes; archive-index.json maps portable filenames to original local paths and SHA256 values. The local .gitattributes prevents line-ending conversion of archived evidence.

This is **not a complete replay bundle**: binaries, full generated scenes/height/surfaces, and the full raw browser traversal remain in local ignored work directories. A fresh clone cannot run the original candidate closure solely from this archive. Reproduction requires the documented build/generation process and new evidence paths. No old report is rewritten to claim a new run.

The stored source manifest predates later checker/document deltas; use inspector-identity-u1.json and the acceptance record together. Git commits identify the published source snapshot separately from historical raw-file hashes.
