## 2. 修改方向：由“采样最窄宽度”改为“给定带的覆盖证书”

### 2.1 数学对象

对非退化直线段的平面投影，令d=b_xz-a_xz、n为单位横向向量：

    P(t,s) = a_xz + t*d + s*n
    t∈[0,1]，s∈[-r,r]，r=当前能力要求的半宽。

目标是证明这个闭通行带在有效承托层被真实支持面并集覆盖。每个矩形在(t,s)系中给出凸多边形/线性半平面约束；纳入所有与目标带相交的部件，**包括永不经过中心线的侧向补宽部件**。

沿楼梯不同高度的顶点不得靠插值生成不存在的支持面。高度/接续关系单独按真实踏面、平台、端口、部件身份和已有步高合同处理，再对每个有效层的平面支持求证；不能把不同高度矩形的投影当作同层并集。

### 2.2 推荐实现：有限扫描线/多边形覆盖，不新引入大依赖

允许抽出一个小型纯几何模块，避免继续在巨大源码尾部做字符串手术。优先在现有依赖下实现有限凸多边形的确定性覆盖扫描：

1. 将有效层支持矩形裁切/变换到目标带坐标，保留真实part id及每条边界的来源。
2. 事件覆盖多边形有效边段的起止/顶点、相交边界及它们与s=-r、s=r、必要时s=0的交点。不能只调用当前中心线segment_events；必须处理同侧边界换序、横向区间相交和分量连接改变。
3. 在相邻事件之间，先证明活动边与边界顺序恒定，再以一个代表截面完成该开放区间的覆盖判定。这里中点检查成立的原因必须是**完整事件保证组合关系不变**，不是采样足够密。
4. 在截面合并真实横向区间，判断[-r,r]是否完全被覆盖。连通并集的边界为min(low)、max(high)，不是max(low)、min(high)的交集。正间隙不得跨过。
5. 单独检查事件截面与整段端点；内部折点分别按入向/出向检查，合法接续另按实际支持关系判定。封闭面共边可接触，不要求部件内部重叠。
6. 对每个已证明区间生成有效层、参与部件、区间范围和要求带的覆盖证书；失败生成缺口/不足覆盖的代表位置或区间。

也可采用等价的“目标带减去支持面并集”几何算法，但必须说明它为什么能判定完整覆盖及边界情形，不能退回有界采样。

**禁止沿用错误定理**：矩形集合恒定，并不自动使其并集边界成为固定仿射函数；并集边界包络和候选层取优都有分支。无需计算一般情况下真实最大可用宽度，先证明本能力所需带宽即可。

### 2.3 数值与成本

- 输入有限性、退化段/部件、平行边、共线共边、重复事件、事件排序、微小间隙需有明确分支。
- 不用大epsilon合并事件抹掉几何缺口；现有接触容差不是任意水平孔洞的通过许可。
- 不确定排序/相交不能“取一个较好值”；返回明确数值不确定，并保持合法整齐正例通过。
- 明确算法N/E规模与事件上限，事件爆炸结构化拒绝，不退化为采样放行。本包输入上限：人工栅格≤64×64、结构≤64、图节点≤512、边≤1024；新求证器事件数建议硬帽65536，达到上限返回coverage_budget_exhausted（可调低但不得无界）。
- 构造全部pair交点必须有事先规模检查/增量上限，不能生成巨量数据后才检查。

### 2.4 层与支持身份

- 有效层候选必须来源于该段实际相邻踏面/平台/端口，而非任意owner部件的“更好高度”。同层容差沿原合同，不能形成跨层传递合并。
- 如果保守地要求每个细分区间由一个真实层完整支持，必须按真实承托切换事件细分，并验证最小楼梯通过；不能以max(min)下界为由提前声称不误拒。
- 换层需要真实接出/接入部件和接缝，符合原步高与净宽；禁止局部随意跳到没有接续的另一高度。
- parts记录实际为完整带贡献的部件集合，而非只记录含中心线的部件。可以记录完整覆盖分量的确定性部件超集，但必须说明其含义；不得遗漏实际补宽者而归因给中央面。
