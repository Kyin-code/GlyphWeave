## 2. 撤销旧禁令：路边站点可以换位置

R6–R9 任务书里“不得删除、移动、缩小路边站点”的条款已随 R11 作废，这里再明确一次：**路边站点落在道路哪个站位，是放置算法的内部决定，不是项目负责人的输入**，你可以改。D8 的诊断说明固定落在道路中心点（纵断面最低处）正是入口台阶的来源，换到抬升量为 0 或可在可用坡长内走通的站位，是合理方向。

约束只有章程底线：不调松 25% 可通行判据、填方上限、垫层平整等数值；不改需求数量与 zoning。

说明一点：垫层高度取“窗口内道路要求地表最大值”是检查员在 R7 定的规则 A′。它现在导致垫层比所临道路高 1.3–1.8 m。如果数据表明换一种定高方式（配合换站位）更好，你可以推翻 A′，在 decisions.jsonl 里写明依据即可。
