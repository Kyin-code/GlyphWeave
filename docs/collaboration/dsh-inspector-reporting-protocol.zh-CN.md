# DSH → 主检查员交付规范（2026-09-20）

## 目的

沿用原有授权与证据边界，不因换task或模型重置。减少用户手工转达：一个批准任务整包执行，正常白名单内编译/人工合成修复连续完成；只在明确越界、自然技术失败/预算耗尽或整包结束时报告。不发“已收到裁定，请批准下一小步”。

## 每包消息固定结构（建议主体不超过约1200中文字，细节进附件）

1. **本轮一句话结果**：明确completed / partial / blocked及已完成、未完成；不要把“尚无候选”自动写成“不存在候选”。
2. **证据矩阵**：claim_id | 精确命题与适用域 | 证据类型 | 文件+JSON路径/代码行 | verdict。证据类型限：生产现场观测、保存面离线复算、人工fixture、数学条件证明、假设/未知。测试PASS另列，不能放进命题verdict代替证明。
3. **本轮新信息**：最多3条，说明相对前轮真正推进了什么。已有结论不铺陈多轮历史。
4. **来源/预算**：执行源码快照/hash与当前源码分列；累计编译/合成命令次数、自然次数、图/格数/耗时。未计量=unknown/not_instrumented。原文件、后续修正版不可混称运行版本。
5. **阻断/下一步**：已批准可继续的工作不要再请求。需要新授权时只提一个推荐包，说明固定输入、唯一变量、预期信息增量、正负分支、累计上限；无完整候选就不申请“一个候选面自然跑跑看”。
6. **交付**：主回执、主报告、运行/派生机器证据路径；一次完整只读hash核验，准确报份数和源码取代。旧证据不覆盖。

## 证明/实验要求

- 命题为“所有/唯一/至少/不可能/最短下界”时，必须有量词域、假设、穷尽性/证书与反例检查；不能以筛过一些边或assert某个期望数代替。
- 保存面旧失败→所有新候选不变，必须证明相关相邻采样对全部非零权重邻格被约束，或提供其它明确不变性证明；仅端点、仅floor、仅整格差均不足。
- 距离/坡度/时间/字节与算法必须显式带单位；“矩形块数”不是“1m台阶数”，离散扫描不是连续优化。
- 理论下界明确是欧氏、octile、指定折线还是实际route；列举门的最小值只适用于已证必经且穷尽的门集合。
- 回归测试应捕捉可能错误（遗漏方向、侧带邻格、条件前提），不要只把自己报告中的结论写成assert然后宣布“已证”。
- 自然结果不利不是程序错误，不为取得正结果改参重跑；人工fixture失败可按已授权范围正常修复。
- 阶段产物冻结后不可删除再生来伪装重跑不变；需要再次运行，输出到新目录或将核对与生成分离。复算相同要报告输入/源码版本和两份输出hash。

## 接续与知识层级

接手先读最新检查员裁定和具体任务白名单；报告等级(A/C)或SOP只是索引，不是新的执行授权。引用前轮结论必须查是否被后续裁定撤回。当前G16的范围性裁定见b01-g16-inspection.zh-CN.md。

里程碑A保持原签收；B partial/C不推进。只有真实受审计增量才可进入后续签收，不因“完成很多包/测试全绿/模型更换”改变此状态。
