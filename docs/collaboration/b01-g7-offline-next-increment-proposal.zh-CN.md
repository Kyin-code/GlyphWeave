## 2. 首选目标窗口

**首选：station 18 的北/南两窗（同一站点、同一 profile 值）。** 定量理由：

1. 它是唯一**处于 B 饱和段**、因而小改动即 1:1 传导的窗口（2280 = B − 80×9，两态一致）；
2. 几何必要修正量最小：北 +27、南 +110，站点层面由南侧决定 → **B ≥ 3110mm**，即 **+110mm**；
3. 填方侧余量极大：所需 pad 2390mm 对 fill 上限 7726/7773mm（约 5.3m 余量），路床 6000mm 与 zone 容量（88–117m）都不构成约束；
4. 几何窗口沿用现有坐标，不新增 station/坐标/宽度/setback，原需求与顺序不变。

**次选（本轮不建议执行，仅登记）**：station 42 北/南。它需要在 B ≥ 3745 才开始响应、B ≥ 4658 才满足 no-cut（+1658mm），会把 AB 从 8000 到该平台的下降与填方包络改动得远大于 st18 方案，风险面显著更大，留待 st18 结论明确后再议。

**另一类窗口**：st90 的 R2 配置由 C 支配且当前 C 正好等于其阈值（3000），但它的阻塞是支撑变化类（§4），不是 no-cut，因此不作为本提案的抬高程目标。

## 4. 必要条件 / 未验证环节 / 两种可区分结果

**两种可区分结果**（不预设成功）：

* 结果甲：st18 两 pad 通过 no-cut 并走完 preflight → 要么得到**首个真实新增地块**（届时报告 realized ids 与各审核状态），要么暴露一个**新的后续类别**（同样是有价值的信息）；

## 8. 勘误（B01-G8 轮追加，2026-09-19）

独立审查 `b01-g7-offline-next-increment-inspection.zh-CN.md` 接受本提案为首个受控实验输入，同时要求纠正下列措辞与来源口径。本节**只追加**：G7 回执文件本身未改写（字节与 sha256 见 B01-G8 回执），其余 G7 证据文件未动。

2. **纵向 solver 不含 carve 合成。** `road_alignment::solve` 由自然下界、固定端点与坡度约束决定最小包络，填方上界用于可行性拒绝；carve 合成不参与该纵向求解。本文 §1 的 `endpointRule` 提到"natural / fill / carve composition sets the level"应改为：**设计由自然下界与端点传播决定**；carve 合成只影响采样层（§5）。

4. **两点自然值可读，不是 unknown。** 冻结 natural 文件中 (196,171) = **−606mm**、(196,188) = **−535mm**；冻结 `scene.json` 也保留实体几何，只是 G6-R1 候选包没有保存全部实体。因此不能说"整个证据集合没有这些数据"；**精确的 before 填方贡献者仍未确定**，也不据此授权 carve 重放。
