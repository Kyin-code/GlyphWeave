# r40：农村田块的有界绕行通道

日期：2026-09-07。权威仓库：G:\difyllmwiki\GlyphWeave。

## 1. 从实际拒绝原因出发

r39默认seed=7样例只有24个田块。检查真实拒绝记录发现：59个候选被田面12%坡度挡住，另有通道8%坡度、160m接入距离、现有用地及只尝试两种L形通道等问题。

本轮不把这些全部归咎于路径算法：**同规则运行seed=7后仍为24个田块**。它的剩余主要约束不能通过绕行解决。必须保留这一结果，不能通过降低坡度门槛、换seed后声称原场景已修好或涂色增加农村面积。

有界绕行作为通用能力，在相同参数的seed=42中确实增加了6个田块。新旧对照必须使用同一seed=42输入；seed=7的未改善结果也同时保留。

## 2. 模块和合同

新增 bevy/crates/core/src/settlement/farm_access.rs，承接：

- 多起点、多个真实道路目标的确定性A*搜索；
- 2m中心网格、曼哈顿长度、节点扩展预算；
- 直线点压缩、路径长度复算、稳定道路ID选择；
- 成功、无可验证路径、搜索预算耗尽等明确结果。

agriculture.rs仍负责土地所有权、水体、地形坡度、硬实体/既有农地保护，以及真正的土壤/地头/通道mesh输出。搜索模块不能自行修改地形或土地角色。

农业模型升级为 rainfed-field-bounded-detour-v2。FarmField新增：

- accessMethod：direct_axis_route 或 bounded_grid_detour；
- accessLengthM：由实际折线复算的米制长度；
- accessSearchExpanded：绕行实际扩展节点数，直达路线为0。

生成器revision为 worldgen-2026-09-07-r40-farm-access-detours。旧schema产物需用对应旧CLI检查，新版使用fresh bake；不能混用二进制和发布文件。

## 3. 保留旧布局的两阶段规划

1. 按原候选顺序完整执行既有直达/L形路线规划。
2. 直达可用的田块及通道先落实，保持原有结果。
3. 仅把田面本身可用但直达失败的候选放入第二阶段队列。
4. 第二阶段重新检查候选是否已经被第一阶段通道或田块占用；不可用则明确拒绝，不挤掉旧田块。
5. 在原始长度预算内搜索绕行。已有公共道路和已实现的场外农用通道可被使用，但不能穿过别的田块。

这是一种保守的增量布局，不是全局农业面积最优解。它刻意不重排原来的可用田块，因此有些理论上通过重规划能容纳的布局仍会被拒绝。

## 4. 不变的准入限制

- 田面全像素最大坡度12%；
- 农用通道全宽4m，非既有道路部分最大坡度8%；
- 实际路线总长不超过160m；
- 目标必须是实际存在的道路实体，终点4m支撑面位于道路矩形内；
- 不能穿水体、运河、硬实体、既有农地/牧场/公园、保留土地或人行入口铺装；
- 不自动缩小田块/通道，不填掉水体，不改自然或最终高度场。

上述坡度/宽度/长度是项目策略参数，不是引用任何国家工程法规。

## 5. 搜索不是中心点碰撞近似

每个2m网格候选中心都验证完整4m×4m支撑面覆盖的16个1m单元。相邻中心距离2m，轴向移动的支撑面连续重叠；得到路径后仍按path_cells重新扫描整条压缩折线的实际4m宽走廊。

成功后真正生成：

- 16×16m耕作面；
- 周边地头作业面；
- 按土地来源分段的通道三角形mesh。

通道已被先前路径实现的单元不重复计面积；路径中的自身地头和既有道路也不重复生成通道面。

本轮仍固定24m田块，不是多尺度农业；转弯处使用方形走廊相交，尚未模拟农机转弯半径、车辆动力学、路基排水或灌溉。

## 6. 有界性能和确定性

- 每个绕行最多扩展4096个节点；预算耗尽是拒绝原因，不伪装“数学上无路可走”。
- 距离预算外道路在每次搜索前剔除，避免每个启发式估计扫描整个地图所有道路。
- 世界1m可行性复用农业原有缓存；当前候选内再缓存中心点可行性。
- 起点排序、道路ID选择、优先队列次序固定；不依赖HashMap随机顺序。
- 该约束限制单次搜索，不是完整6km×10km生成时间或峰值内存证明。

## 7. 验证

### 核心

- 绕过障碍后路线真实存在、折线轴向、长度守恒、同输入复现；
- 超长度、完全隔离、扩展预算耗尽不能报告成功；
- 多道路ID平局、起点重复、正负大origin结果稳定；
- 农业完整fixture中，所有旧直达候选被岩石挡住，但允许绕行时生成真实田块及4m走廊；
- 整条通道mesh不与岩石相交、不重复占地，且不进入耕作内部；
- 全宽封堵或仅2m空隙时仍无田块，不能把窄缝当4m通道；
- 既有坡度、保护地、水体、入口铺装测试保持有效。

### CLI

seed=42实际fresh bake必须有detour字段。质量报告独立重建成功；同时伪造scene和landcover-surfaces中的方法、长度、扩展数或转折点必须被拒绝，恢复后再通过。

### HTML

增加只读查看参数：view=farm&field=<Rust田块ID>，可定位新增绕行田块。未知ID报错，不悄悄展示其它田块。

check-preview-farm-access.mjs逐patch核对耕作、地头、通道的实际Three顶点、索引和材质标记，必须存在非空绕行田块；不能仅证明JSON里有字段。

## 9. 后续必做与许可证边界

绕行无法解决seed=7主要坡度约束。下一步需要地形与用地联合规划、显式且受审计的田块整地、低地排水和多尺度田块/牧场；不能继续只增加路径花样。城市剩余地块、自然地貌质量、完整60km²性能和最终视觉仍未完成。

本轮没有新增第三方依赖、下载资产或复制外部源码；搜索是项目内部的标准A*领域实现，不是Mapgen4或symbios-ground移植。未改变现有第三方许可证关系。
