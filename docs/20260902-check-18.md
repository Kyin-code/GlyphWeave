## 真实参数问题（不是未实现问题）

基线已经确认：

1. 深圳湾 urban/nature 面积比例与 profile 目标偏差显著；
2. 内蒙古草原 profile 没有生成 rural 面积，输出趋向纯自然对象；
3. 所有示例仍缺少 scale-audit 产物；
4. rotation/anchor 虽已进入数据结构，但大多数生成器尚未写出非零朝向或真实入口；
5. world_y 仍为 i32，0.25m terrain 精度尚未端到端传递到实体 pivot。

## 下一步建议

不要再以“功能未实现”为由扩张范围。下一阶段应使用已建立的 4 份基线，逐项校准：

- land-use profile 的实际面积；
- road/bridge/building grounding；
- asset contract 的 pivot、direction 和 size；
- rotation/anchor 的生成规则；
- scale-audit 成为 baseline 的必经 gate。

## 总结判定

**世界数据契约 v1 通过。**

系统现在不会静默丢弃 sceneGraph；输出明确说明 sidecar 是 terrain 权威；实体拥有保留空间语义的字段；真实示例可重复并可回归比较。

仍未完成完整单文件 gemap 发布、0.25m entity pivot、高级几何和渲染端完全消费契约；这些应在参数校准之后继续推进。
