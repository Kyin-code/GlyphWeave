## 1. 背景

用户反馈：

1. 8778 预览中桥体消失，只剩桥面/路面；
2. 精简深圳湾没有充分体现大岩石、山体、丘陵、购物中心、写字楼、便利店、围栏、护栏、步道、景观带、红树林、滩涂、夜市、社区广场等通用要素；

## 6. 当前仍需后续完善

以下不阻塞本轮固定场景测试，但尚不能宣称最终完成：

1. 沿海素材当前主要是程序化低多边形几何，尚不是完整真实资产库；
2. 围栏、护栏、步道当前仍以单段线性对象为主，多段线/曲线段需要独立 geometry contract；
3. landform 目前是可见体积和规则语义，尚未完全成为地形高度场中的连续山体；
4. 购物中心、写字楼等比例属于生成器初始范围，不是深圳真实建筑的测量复刻；
5. rules placement 报告中的候选拒绝数量较多，表示规则正在过滤旧模板候选，不代表最终 scene 中存在碰撞；
6. HTML 2.5D 仍然是预览适配器，最终渲染资产、pivot、LOD 和长期性能还需要单独建设。
