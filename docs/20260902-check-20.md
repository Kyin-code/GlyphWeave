# 通用世界意图归一化与生成入口验收（第 20 次）

- **日期**：2026-09-02
- **目标**：将 Agent/自然语言的职责限定为“提取明确事实、报告缺失字段、产出可确认的世界意图”，而不是让 Agent 直接写高度图、实体坐标或二进制分块。

## 本轮原则

本轮没有为深圳湾、内蒙古等测试场景增加专用分支。它们继续只是回归样例。

新增的是通用层：

```text
自然语言
  -> IntentDraft（可审查；缺失字段显式列出）
  -> WorldIntent（用户/Agent 确认后的强类型意图）
  -> WorldManifest（唯一生成输入）
  -> Rust generator
```

## 新增 Core 模型

文件：`bevy/crates/core/src/intent.rs`

- `WorldIntent`
- `IntentScene`
- `TerrainIntent`
  - plain / coastal / river / lake / steppe / mountain
- `SettlementIntent`
  - city / town / pastoral / wilderness
- `WaterIntent`
  - none / river / lake
- `IntentDraft`

`WorldIntent.compile_manifest()` 把通用意图编译为标准 `WorldManifest`，并写入：

```text
style.generationIntent
style.terrainProfile
style.landUseProfile
style.water
style.naturalOnly
```

`pastoral` 与 `wilderness` 被明确区分：

- pastoral：不是纯自然，允许后续农牧地/聚落生成；
- wilderness：才设置 `naturalOnly=true`。

## 新增 CLI

```text
glyphweave intent draft INPUT.txt OUTPUT.json
glyphweave intent validate INTENT_OR_DRAFT.json
glyphweave intent compile INTENT_OR_DRAFT.json MANIFEST.json
```

### draft 行为

`intent draft` 只提取文本中显式出现的：

- 名称；
- seed；
- 尺寸；
- 地形线索；
- 水体线索；
- 定居类型。

缺少关键字段时：

- 仍写出 Draft，便于 Agent/用户查看；
- 返回非零退出；
- `missingFields` 明确列出缺项；
- 不会伪造名称、seed、尺寸或定居类型。

这符合“关键字段先追问、不能静默补写用户意图”的原始要求。

## 实测

完整中文输入：

```text
名称：通用海湾，seed=20260902，2km x 1km 的沿海城市
```

结果：

```text
intent draft: ready=true
intent validate: pass
intent compile: generated manifest
```

不完整输入：

```text
我想生成一个沿海城市。
```

结果：

```text
EXIT 1
missing=name, seed, scene size
```

## 单元测试

- 缺失字段不会被编造；
- 完整中文意图可编译为 Manifest；
- pastoral steppe 不会被误编译为 pure wilderness。

## 当前限制

- 这不是本地 LLM，也不尝试理解任意自然语言；它是确定性、受限的归一化安全网。
- Agent/LLM 应输出或补齐 `WorldIntent`，再由 Rust 编译器验证；不应直接生成世界二进制。
- 当前 structured-water scene 仍没有 profile-driven land-use pass。该能力缺口已由 quality-report 标为 `landUseProfileApplied=false`，不应通过测试样例硬编码解决。

## 判定

**通过。** Agent 自然语言归一化现在有可审查、可失败、可编译的正式入口；地图生成器仍以通用 Manifest/Intent 为输入，而不是以具体场景名称分支。
