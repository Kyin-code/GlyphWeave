# 20260903-check-29：地貌重梳理与地表语义第一、二阶段验收

## 1. 验收范围

本轮执行了渲染重构计划中的前两阶段，不尝试以草、后处理或 shader 位移掩盖地貌问题：

1. 建立 worldgen 到 adapter 的正式地表语义契约；
2. 将可见的中尺度自然起伏写入权威 baked heightfield。

目标是服务通用地图生成器与自然语言归化，而不是为单一测试场景加入特判。

## 2. 实现内容

### 2.1 新的 terrain semantics sidecar

新增 `*.terrain.bin`，每个 1m 栅格包含四个字段：

```text
slope_degrees_u8
curvature_signed_u8
wetness_u8
disturbance_u8
```

- height 仍在既有 `*.height.bin`；
- land cover 仍在既有 `*.surface.bin`；
- terrain semantics 由 baked 高程、水体/气候和 terrain carve 推导；
- scene chunk descriptor 新增可选 `terrainFile`；
- `sidecar.json` 新增 `terrainSemantics` 合约；
- `validate-world`、`scale-audit` 与 chunk hash 都覆盖新 payload。

### 2.2 中尺度地貌

新增 `mesoscale_relief()`：

- 以世界坐标决定；
- 使用 domain warp、310m swell 和 145m fold；
- 生成约 80–360m 尺度的柔和起伏与浅沟；
- 写入权威 heightfield；
- 不依赖场景名称或固定坐标；
- renderer 不再需要自己添加危险的几何位移。

### 2.3 HTML 地面消费

`makeMCTerrain()` 改为接收：

```text
heightView, surfaceView, terrainView
```

它根据绝对高程、land cover、坡度、曲率、湿润度、工程扰动与季节预设生成顶点色。原本每 chunk 独立 min/max 色阶已移除，避免相邻 chunk 的草色各自重映射而形成色块。

## 7. 不通过与后续项

1. 尚未把 `makeSteppeGroundMaterial()` 的 PBR 层安全接入正式 steppe 路径；本轮先保证数据契约和顶点色路径正确。
2. 草、树、灌丛仍未消费同一个 terrain semantics/wind 语义。
3. 旋转建筑的接地采样与 terrain carve 尚未完全使用旋转后 footprint，这是既有 P1，不能因本轮通过而忽略。
4. `rules audit` 的 footprint/pivot 与 worldgen 仍需统一，当前继续作为诊断而非阻断门禁。
5. 需建立多主题截图基线，不能只以 river-delta fixture 判断风格化地貌质量。

## 8. 结论

**第一、二阶段的数据侧验收通过，可用于继续做正式地表材质、草木覆盖与多场景视觉验收。**

本轮完成的是“让 renderer 有正确、可共享的地表输入”与“让自然地貌有中尺度几何基础”；并未宣称最终视觉目标已经完成。
